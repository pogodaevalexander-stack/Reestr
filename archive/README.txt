Архив записей реестра

Приложение при первом обращении в каждом календарном месяце сохраняет JSONL-снимок всех обращений и отключений, созданных за последние три месяца. Файлы именуются YYYY-MM.jsonl и только дополняются; повторный запуск в течение месяца не дублирует уже сохранённые записи. Для работы веб-серверу нужны права на запись в эту папку.

Архив хранится вне public/, поэтому файлы напрямую не доступны из браузера.
