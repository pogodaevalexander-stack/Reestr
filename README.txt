--------------------------------------------------------------------------------
 1. ЧТО ПОТРЕБУЕТСЯ
--------------------------------------------------------------------------------
- Windows 10/11
- XAMPP - готовый локальный сервер (Apache, PHP, MariaDB, PhpMyAdmin):
  https://www.apachefriends.org/ru/index.html
- Прочий софт не нужен: ни Composer, ни Node.js (только PHP 7.4+).
- Для карты и подсказки адресов - бесплатный ключ Яндекс Карт API
  (без ключа приложение тоже работает, карта будет отключена).

--------------------------------------------------------------------------------
 2. УСТАНОВКА XAMPP И ЗАПУСК PHPMYADMIN
--------------------------------------------------------------------------------
Шаг 1. Скачайте и установите XAMPP по умолчанию в папку C:\xampp.

Шаг 2. Запустите "XAMPP Control Panel" (ярлык на рабочем столе) и нажмите
       Start рядом с Apache и MySQL.
       Оба модуля должны показать зелёный статус "Running".

Шаг 3. PhpMyAdmin уже входит в состав XAMPP:
       - откройте браузер и перейдите на http://localhost/phpmyadmin
       - либо нажмите кнопку "Admin" (иконка слона) напротив MySQL
       Логин: root   Пароль: (пустой) - по умолчанию в XAMPP

Шаг 4. Проверьте, что PhpMyAdmin работает: на главной странице видны
       вкладки SQL/Импорт и список баз (mysql, information_schema и т.п.).

--------------------------------------------------------------------------------
 3. СОЗДАНИЕ БАЗЫ ДАННЫХ (reestr)
--------------------------------------------------------------------------------
СПОСОБ А - импорт готового файла (рекомендуется):
  Внимание: импорт пересоздаёт houses, outages и appeals и очищает их содержимое.
  Таблица accounts создаётся пустой.
  1. В PhpMyAdmin нажмите вкладку "Импорт" (Import).
  2. Кнопка "Выбрать файл" -> укажите D:\Reestr\sql\reestr.sql
  3. Нажмите "Выполнить" (Go).
  4. В базе "reestr" появятся таблицы accounts, houses, outages, appeals.
     Таблицы адресов, отключений и обращений будут пустыми.

СПОСОБ Б - выполнить SQL вручную:
  1. Вкладка "SQL" -> вставьте содержимое файла D:\Reestr\sql\reestr.sql
  2. Нажмите "Выполнить".

СПОСОБ В - из командной строки:
  C:\xampp\mysql\bin\mysql.exe -u root --default-character-set=utf8mb4 < D:\Reestr\sql\reestr.sql

--------------------------------------------------------------------------------
 4. РАЗМЕЩЕНИЕ ПРОЕКТА
--------------------------------------------------------------------------------
Проект лежит в D:\Reestr. Apache отдаёт только файлы из C:\xampp\htdocs,
поэтому папку нужно "прокинуть" в htdocs. Два варианта:

ВАРИАНТ 1 - символ папки (рекомендуется, проект остаётся на диске D:):
  1. Пуск -> введите cmd -> "Запуск от имени администратора".
  2. Выполните команду (пробелы и кавычки важны):
     mklink /J "C:\xampp\htdocs\Reestr" "D:\Reestr"
  3. Либо просто запустите готовый скрипт:  D:\Reestr\setup.bat

ВАРИАНТ 2 - копия:
  Скопируйте папку D:\Reestr целиком в C:\xampp\htdocs
  (получится C:\xampp\htdocs\Reestr). Настройки менять не нужно.

--------------------------------------------------------------------------------
 5. НАСТРОЙКА
--------------------------------------------------------------------------------
Файл D:\Reestr\src\config.php:

  base_url - оставьте '/Reestr', если открываете http://localhost/Reestr/
             (ставится '', только если корень сайта указываете на public/).
  db       - стандарт XAMPP: user "root", pass "" (пустой).
             Если меняли пароль в XAMPP - впишите его сюда.
  yandex_maps_api_key - ключ сервиса JavaScript API Яндекс Карт.
  yandex_geocoder_api_key - отдельный ключ HTTP Геокодера.
  Для работы карты и подсказок нужны оба ключа.

Ключи API Яндекса:
  1. Войдите в кабинет разработчика: https://yandex.ru/maps-api/console/
  2. Подключите сервис JavaScript API и создайте ключ. Вставьте его в
    yandex_maps_api_key в src/config.php.
  3. Отдельно подключите HTTP Геокодер API и создайте его ключ. Вставьте его
    в yandex_geocoder_api_key.
  4. Для JavaScript API добавьте разрешённый домен localhost (и домен проекта,
    если он не локальный). Не публикуйте ключ Геокодера в репозитории.
  5. Сохраните config.php и перезагрузите сайт. Для карт и подсказок адреса
    поиск и карта ограничены Омском.
  Яндекс может запросить привязку платёжного аккаунта/подтверждение условий;
  доступность бесплатного тарифа и условия проверяйте в кабинете сервиса.

Добавление аккаунтов:
  Сначала импортируйте БД, затем запустите D:\Reestr\add_account.bat,
  введите логин и дважды пароль.
  Пароль вводится скрыто и хэшируется в PHP перед записью в accounts.

Клонирование из GitHub:
  1. Скопируйте src\config.example.php в src\config.php.
  2. Заполните локальные настройки БД и ключи API в src\config.php.
  3. Импортируйте sql\reestr.sql и создайте первый аккаунт через add_account.bat.
  src\config.php исключён из Git; реальные ключи и пароли не публикуйте.

 6. ЗАПУСК ПРИЛОЖЕНИЯ
--------------------------------------------------------------------------------
  1. XAMPP Control Panel: Apache - Running, MySQL - Running.
  2. Откройте в браузере:
       http://localhost/Reestr/                  - Главная (карта + статистика)
       http://localhost/Reestr/outages.php       - Отключения + база адресов
       http://localhost/Reestr/appeals.php       - Обращения граждан
  3. Быстрая проверка API (должен вернуться JSON со статистикой):
       http://localhost/Reestr/api/index.php?action=stats

--------------------------------------------------------------------------------
 7. БЫСТРАЯ ПРОВЕРКА ФУНКЦИОНАЛА
--------------------------------------------------------------------------------
- Главная: цифры статистики считаются с анимацией; на карте маркеры
  отключений (жёлтые - ГВС, красные - отопление, зелёные - звонки);
  чипы-переключатели скрывают/показывают слои; справа - звонки за день.
- Отключения: зарегистрируйте отключение у одного из домов, затем нажмите
  "Восстановить" - маркер исчезнет с карты, счётчики и бейджи обновятся.
  Поиск работает по ID, адресу, типу, причине; есть фильтры типа и статуса.
- Обращения: начните вводить адрес - выберите вариант из подсказок Яндекса
  (появится значок "Яндекс", адрес запишется в едином формате), заполните
  ФИО и телефон -> Сохранить. Найдите запись поиском по ID/ФИО/телефону,
  отредактируйте или удалите (двойное нажатие - подтверждение).

--------------------------------------------------------------------------------
 8. ЧАСТЫЕ ПРОБЛЕМЫ
--------------------------------------------------------------------------------
* Порт 80 занят (Skype, IIS и т.п.):
  C:\xampp\apache\conf\httpd.conf - замените "Listen 80" -> "Listen 8080"
  и "ServerName localhost:80" -> "ServerName localhost:8080";
  перезапустите Apache, откройте http://localhost:8080/Reestr/

* SQLSTATE[HY090] [1049] Unknown database 'reestr':
  база не импортирована - см. пункт 3.

* SQLSTATE[HY000] [1045] Access denied for user 'root':
  в XAMPP стоит пароль. Либо впишите его в config.php, либо сбросьте:
  PhpMyAdmin -> Пользователи -> root -> Пароль.

* Карта не отображается:
  проверьте yandex_maps_api_key в src/config.php и интернет; F12 -> Консоль:
  нет ли ошибок загрузки api-maps.yandex.ru.
  Без ключа карта отключается намеренно - это штатно.

* Подсказка адресов не работает, а карта есть:
  проверьте yandex_geocoder_api_key и подключение HTTP Геокодера API в кабинете.

 9. СТРУКТУРА ПРОЕКТА
--------------------------------------------------------------------------------
  D:\Reestr\
  |- README.txt            <- этот документ
  |- setup.bat             <- быстрая установка (символ htdocs + импорт БД)
  |- add_account.bat       <- создание аккаунта с хэшированием пароля
  |- tools\add_account.php <- скрипт создания аккаунта
  |- sql\
  |  \- reestr.sql         <- схема БД без демо-данных
  |- src\
  |  |- config.php         <- локальные настройки (не добавляется в Git)
  |  |- config.example.php <- образец настроек без секретов
  |  |- bootstrap.php      <- автозагрузка, PDO, JSON-помощники
  |  \- repositories\
  |     |- HouseRepository.php
  |     |- OutageRepository.php
  |     \- AppealRepository.php
  \- public\               <- корень сайта (то, что отдаёт Apache)
     |- index.php          <- Главная: карта + статистика
     |- outages.php        <- Отключения + база адресов
     |- appeals.php        <- Обращения граждан (CRUD)
     |- api\index.php      <- единая JSON-точка для JS
     |- partials\          <- head.php / footer.php (каркас страниц)
     \- assets\
        |- css\app.css
        \- js\             <- common.js, main.js, outages.js, appeals.js

 10. API (JSON)
--------------------------------------------------------------------------------
  GET  api/index.php?action=stats                           статистика
  GET  api/index.php?action=map                             объекты для карты
  GET  api/index.php?action=houses&op=list&q=...            список домов
  POST api/index.php?action=houses&op=create|update|delete
  GET  api/index.php?action=outages&op=list&q=&type=&status=
  POST api/index.php?action=outages&op=create|update|delete
  GET  api/index.php?action=appeals&op=list&q=&today=1
  POST api/index.php?action=appeals&op=create|update|delete

  Ответ всегда: { "ok": true, "data": ... }
                 { "ok": false, "error": "..." }

  Типы отключений: hot_water - горячая вода (ГВС), heating - отопление.
